# План реализации Aetherfall

Документ ведётся по ходу работы: отмеченные пункты сделаны и проверены.

## Принципы

1. **Сначала фундамент, потом фичи.** Новая система на нестабильной основе умножает баги, поэтому этап 1 идёт первым.
2. **Каждый шаг завершается проверкой** по чек-листу ниже. Шаг без проверки не считается сделанным.
3. **Честный баланс.** Любое изменение экономики или боёв прогоняется ботом (`scripts/bot.ts`): он проходит игру в ускоренном времени и показывает темп по главам.
4. **Маленькие коммиты.** Один пункт плана — один или несколько коммитов, после каждого CI собирает APK.

### Чек-лист готовности пункта

- [ ] `npm run typecheck` без ошибок
- [ ] `npm test` зелёный, для новой логики есть тесты
- [ ] бот проходит все главы, темп не сломан (если менялся баланс)
- [ ] скриншоты на 1280×720 и 844×390 (телефон) проверены глазами
- [ ] CI собрал APK

## Этап 1. Фундамент качества

Цель — игра не теряет прогресс, не падает молча, держит частоту кадров на слабых телефонах, а установить её можно в один клик.

| # | Задача | Критерий готовности |
|---|---|---|
| ✅ 1.1 | **Аудит кода и исправление багов** в симуляции, рендере и UI | Найденные дефекты исправлены, на каждый — регрессионный тест, где это возможно |
| ✅ 1.2 | **Надёжные сохранения:** основной и резервный слоты, проверка целостности при загрузке, экспорт/импорт сохранения строкой в настройках | Повреждённый основной слот → загрузка из резервного; тест на миграцию старого формата |
| ✅ 1.3 | **Обработка ошибок:** глобальный перехват, экран сбоя с кнопками «Продолжить» и «Скопировать отчёт», восстановление после потери WebGL-контекста | Искусственная ошибка показывает экран, а не белый экран; игра продолжается |
| ✅ 1.4 | **Производительность:** адаптивное качество (снижение разрешения рендера при FPS < 40), счётчик FPS в настройках, пауза рендера в фоне | Без лишних перерисовок в простое; FPS-оверлей включается в настройках |
| ✅ 1.5 | **Расширение тестов:** задания и главы, набеги и защита, титаны, исследования, офлайн-прогресс, лечение, ежедневные задания | ≥ 30 тестов, покрыты все публичные действия `Game` |
| ✅ 1.6 | **Релизная сборка:** подписанный release-APK (ключ из секретов репозитория, при их отсутствии — постоянный публичный sideload-ключ), `versionCode` = номер сборки, автопубликация в GitHub Releases | APK скачивается со страницы Releases без входа в Actions |

## Этап 2. Системы удержания (паритет с лидерами жанра)

Цель — у игрока всегда есть причина вернуться и есть долгосрочные цели.

|---|---|---|
| ✅ 2.1 | **Локальные уведомления:** стройка/исследование/обучение завершены, бесплатный призыв готов, лазарет пуст (Capacitor Local Notifications) | Уведомления ставятся при уходе в фон и снимаются при возврате; переключатель в настройках |
| ✅ 2.2 | **Таланты героев:** 3 ветки (атака / защита / специализация по роду войск), очко за уровень, сброс | Таланты влияют на бой (тест), UI-дерево с подсказками |
| ✅ 2.3 | **Кузница и снаряжение:** 6 слотов, 4 редкости, наборы с бонусами, материалы из логов, руин и разломов | Экипировка меняет статы в бою (тест), крафт и разбор в UI |
| ✅ 2.4 | **Ротационные события:** «Охота на Пустоту» (очки за победы), «Великая жатва» (очки за сбор), «Ночь Пустоты» (волны на город) — с этапными наградами и таймером | События сменяются по расписанию, награды выдаются один раз (тест) |
| ✅ 2.5 | **Союз (ИИ-альянс):** соратники помогают ускорять стройки, ежедневные подарки, магазин союза за очки вклада, совместный поход на титана | Помощь сокращает таймеры (тест), магазин работает |
| ✅ 2.6 | **Достижения:** 30+ достижений с наградами | Прогресс считается от статистики, награда выдаётся один раз |
