# Правило проекта: вся графика — из генератора изображений

- Всё, что игрок видит как изображение (здания, объекты карты, текстуры, иконки, портреты, рамки и кнопки интерфейса,
  фоны, ключевой арт), создаётся в ChatGPT по промптам из `docs/art/` и подключается импортом.
- Код не рисует новые изображения. Процедурная графика и CSS/SVG-оформление, оставшиеся с ранних версий, — только
  временная замена: каждая деталь исчезает сама, как только для неё появляется сгенерированная картинка.
- Код отвечает за промпты, нарезку, подгонку масштаба и опоры, компоновку экрана, анимацию и эффекты движения.
- Новый вид контента = новый промпт в `scripts/art-prompts.mjs` + подключение в движке с откатом.
